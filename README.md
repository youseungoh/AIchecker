> 글을 붙여넣고 AI 작성 가능성을 확인해 보세요.
> 외부 API 없이 브라우저 안에서 완전히 동작하는 미니멀 웹 도구입니다.

## 소개

학교 현장의 교사와 학생을 위한 AI 작성 패턴 분석 도구입니다.
학생이 제출한 글이 AI가 작성한 것인지를 1차 선별하는 용도로 활용할 수 있습니다.

ChatGPT, Claude, Gemini 등 대형 언어 모델이 만든 글은 일정한 통계적 패턴을 가지고 있습니다.
이 도구는 그 패턴을 5가지 지표로 분석하여 AI 작성 가능성을 백분율로 표시합니다.

> ⚠️ 본 도구는 통계적 패턴 분석 기반의 참고 지표를 제공합니다.
> 최종 판단은 학생 면담, 작성 과정 확인 등 교사의 종합적 판단으로 내려주세요.

## 주요 기능

### 한눈에 보이는 결과
- 큰 숫자 하나로 AI 작성 가능성(%) 표시
- 신호등 색상(초록·노랑·빨강)으로 직관적 결론 전달
- 결과에 따른 한 줄 판정 메시지 자동 생성

### 5가지 세부 분석 지표
| 지표 | 의미 |
|------|------|
| 문장 균일성 | 문장 길이가 비슷할수록 AI 가능성 높음 |
| AI 연결어 | "또한", "이러한", "결론적으로" 등 AI 빈출 표현 |
| 어휘 단조로움 | 사용한 어휘의 다양성 부족 정도 |
| 반복 구조 | 문장 시작 패턴의 반복성 |
| 비개인적 서술 | "나는", "제가" 등 1인칭 표현 부재 |

### 입력 편의 기능
- 실시간 글자 수 카운트 (공백포함 / 공백제외)
- 예시 텍스트 한 번에 불러오기
- 한 번의 클릭으로 전체 지우기

### 디자인
- Pretendard 한글 폰트 적용으로 가독성 최적화
- 화이트 톤 미니멀 인터페이스 (Notion / Linear 감성)
- 모바일·태블릿·PC 반응형 대응

## 사용 방법

### 1. 다운로드 및 실행
```
ai_checker_minimal.html 파일을 다운로드합니다.
파일을 더블클릭하면 기본 브라우저에서 바로 실행됩니다.
```

### 2. 글 입력
- 검사하고 싶은 글을 텍스트 박스에 붙여넣습니다.
- 100자 이상 입력 시 분석 정확도가 향상됩니다.

### 3. 분석 실행
- 검은색 [분석하기] 버튼을 클릭합니다.
- 약 1초 후 결과가 표시됩니다.

### 4. 결과 해석
| AI 작성률 | 의미 | 권장 조치 |
|-----------|------|-----------|
| 0% ~ 44% | 직접 작성한 글로 보임 | 추가 조치 불필요 |
| 45% ~ 69% | AI 도움을 받았을 가능성 | 구술 확인 또는 추가 과제 |
| 70% ~ 95% | AI 작성 가능성 매우 높음 | 학생 면담 권장 |

## 기술 사양

### 사용 기술
- HTML5 / CSS3 / Vanilla JavaScript
- Pretendard 웹폰트 (Google Fonts CDN)
- 외부 라이브러리 의존성 없음

### 동작 환경
- Chrome, Edge, Safari, Firefox 등 모든 최신 브라우저
- 인터넷 연결 없이도 동작 (웹폰트만 온라인 로드)
- 별도 서버 설치 불필요

### 프라이버시
- 입력한 텍스트는 외부 서버로 전송되지 않습니다.
- 모든 분석은 사용자의 브라우저 안에서 처리됩니다.
- 페이지를 닫으면 입력 내용이 자동으로 사라집니다.

## 분석 알고리즘 원리

이 도구는 다음 5가지 언어 패턴을 통계적으로 분석합니다.

1. **문장 길이 변동계수 (CV)**
   문장들의 길이 편차를 측정합니다.
   AI 생성 텍스트는 길이가 균일한 경향이 있습니다.

2. **어휘 다양성 지수 (TTR, Type-Token Ratio)**
   서로 다른 어휘 수를 전체 단어 수로 나눈 값입니다.
   AI 텍스트는 같은 표현을 반복하는 경향이 있습니다.

3. **AI 빈출 연결어 카운트**
   국내외 LLM이 한국어 작문에서 자주 사용하는 27개 연결어·표현의 등장 빈도를 측정합니다.

4. **문장 시작 패턴 반복도**
   문장의 첫 단어가 얼마나 다양한지 측정합니다.
   AI는 같은 어휘로 문장을 시작하는 경향이 있습니다.

5. **1인칭·개인 경험 표현 비율**
   "나는", "내가", "제 경험에 따르면" 등의 표현 빈도를 측정합니다.
   AI는 객관적·일반적 서술을 선호합니다.

각 지표에 가중치를 적용한 종합 점수를 0~100% 범위로 산출합니다.

## 한계점

- 이 도구는 **확률적 추정치**를 제공하며 100% 정확한 판별은 불가능합니다.
- AI가 작성한 글도 사용자가 충분히 수정하면 낮은 점수가 나올 수 있습니다.
- 학생이 평소 글쓰기 스타일이 균일하고 정형적이라면 높은 점수가 나올 수 있습니다.
- 글의 길이가 너무 짧으면(30자 미만) 분석이 불가능합니다.
- 영어 등 한국어 외 언어는 정확도가 떨어집니다.

**반드시 1차 선별 도구로만 활용하시고, 최종 판단은 학생과의 직접 대화를 통해 내려주세요.**
